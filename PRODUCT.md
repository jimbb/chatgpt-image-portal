# Product

## Register

product

## Users

Self-hosting operators and developers who manage ChatGPT account pools and expose image generation, image editing, search, and document-generation capabilities through OpenAI-compatible APIs. They need to configure the service, monitor account health, and generate images without guessing which settings are active.

## Product Purpose

ChatGPT2API packages selected ChatGPT web capabilities into a self-hosted API and administration panel. Success means operators can configure accounts and network behavior safely, select supported models explicitly, diagnose failures quickly, and use the image workspace with the same persisted configuration as API callers.

## Brand Personality

Practical, precise, and calm. The interface should feel like a dependable operator tool: clear state, direct controls, and concise technical language.

## Anti-references

Avoid decorative SaaS landing-page patterns, hidden autosave behavior, ambiguous controls, excessive cards, and settings that appear active before they are persisted. Do not trade operational clarity for visual novelty.

## Design Principles

- Make active configuration visible and distinguish drafts from saved state.
- Use familiar administration controls and explicit action labels.
- Keep API behavior and web-interface defaults consistent.
- Surface validation close to the field that caused it.
- Preserve dense technical information while maintaining readable grouping and hierarchy.

## Accessibility & Inclusion

Target WCAG 2.1 AA contrast and keyboard navigation. Interactive controls need visible focus states, meaningful labels, non-color-only status communication, and reduced-motion-safe feedback.
