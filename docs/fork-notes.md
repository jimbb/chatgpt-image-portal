# Fork provenance

This is an independent source fork of [jiawen-afk/chatgpt2api](https://github.com/jiawen-afk/chatgpt2api), derived from [basketikun/chatgpt2api](https://github.com/basketikun/chatgpt2api). The functional source matches the evolved local checkout at commit `00bb2d3` plus its uncommitted CPA/image-pool/prompt-library changes. The public history is a sanitized source snapshot without local author metadata, runtime data, deployment configuration, or generated images.

The publication comparison found no missing functional source files. Differences
are limited to publication hygiene: sanitized examples and provider fixtures,
fork-neutral Docker/update configuration, documentation, and omission of the
optional GitHub Actions workflow because the publishing token did not have the
GitHub `workflow` scope.
