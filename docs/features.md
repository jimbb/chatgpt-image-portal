# Features and limitations

The browser workspace supports generation, editing, masks, grid crops, optional
face selection, reference sets, local conversation history, retry batches, and
task polling. The gallery supports filtering, tagging, downloads, deletion,
compression, and storage cleanup.

The server exposes image routes plus compatibility adapters for chat
completions, Responses, Anthropic Messages, search, and asynchronous image
tasks. These are compatibility layers, not complete general-purpose provider
proxies. Account refresh, login, CPA/sub2api import, and exports are
administrator operations. Provider models, quotas, account status, and
upstream behavior are external and can change.
